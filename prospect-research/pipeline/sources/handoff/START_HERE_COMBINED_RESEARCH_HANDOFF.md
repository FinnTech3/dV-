# Combined research handoff for Claude Code

Prepared 10 November 2026. This bundle combines the user's current autonomous master prompt, the original PLAN research pack, and ChatGPT's independent supplementary research.

## Read these first
1. `Autonomous_Prospect_Research_Master_Prompt.md` is the controlling user instruction. Follow its latest target and evidence-grade rules.
2. `Claude_Code_PLAN_Research_Pack.md` is the original base market map.
3. `ChatGPT_Independent_Research_Addendum.md` contains independent supplementary findings and caveats.

## How to merge
- Treat the two research packs as source material, not as prospect records.
- Import all query CSVs into the search library, deduplicating equivalent queries before execution.
- Merge both organisation/directory files, preferring the independent official audit where it provides a more recent or more precise status.
- Merge both event files, preserving venue locality separately from target city and preserving the difference between programmes, speaker lists, exhibitor lists and attendee lists. The independent event shortlist is more curated; recheck dates before use.
- Import city economy evidence and the Berlin Top 50 as employer/source leads, not proof of largest city employers outside the stated geography or period.
- Validate each employer's actual office/establishment location before using it as a city-specific seed. Metro/canton/region statistics must not be labelled as city-only.
- Do not count searches, organisations, companies, events, exhibitors or event participants as prospects.
- Do not infer an individual's previous residence from employment, current residence from an office address, or personal phone ownership from a company switchboard.
- LinkedIn query strings are planning aids only. Do not scrape LinkedIn or automate logged-in account access.
- Use permitted automated sources and tools only. Do not bypass access controls, paywalls, terms, or API limits.
- Refresh time-sensitive event dates and source status on the execution date. The event research window is 10 November 2026 to 10 February 2027.
