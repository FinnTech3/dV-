## How to use this addendum

This is supplementary research, not an individual prospect database. Feed it alongside the earlier Claude Code PLAN pack. ## 7. Practical search cadence for Claude

This is a suggested order, not an unsupported promise of output volume:

**Pass 1: City and origin coverage.** Run the expanded query library in equal city/origin batches so no city or origin country is missed. Check the source register before repeating a query.

**Pass 2: Directory and network enrichment.** Use chamber directories, IPBN, Dutch clubs, Irish networks and professional associations to locate businesses and biographies. Do not attempt to access private member contact details.

**Pass 3: Company-level enrichment.** Follow the employer's official site to confirm workplace city, current status, professional biographies and published work contact pages.

**Pass 4: Telephone completion.** Search official contact pages and permitted telephone directories only after the individual is identified. KVK is not a telephone source. local.ch, PagesJaunes, Páginas Amarillas and Das Örtliche list business contacts but attribution must be checked.

**Pass 5: Evidence grading and reallocation.** Count only records that meet the 1,000-target rules in the current master prompt. If a city/channel produces low phone attribution or weak residence clues, shift effort to higher-yield sources using observed results.

Do not set a fixed daily PASS rate. Report actual candidates, grade distribution, phone attribution and duplication.
